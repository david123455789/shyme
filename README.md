# Syhme

Sistema de operación para una empresa de seguridad, implementado en Google Sheets con Google Apps Script.

Libro de trabajo: [Syhme](https://docs.google.com/spreadsheets/d/1iD82SmTFA0gcwTjOGY0nboEkBtbVun7tH8NagJZXGfI/edit)

## Contenido

- `Code.gs`: menú y módulos operativos de Syhme.
- `appsscript.json`: configuración del proyecto de Apps Script.

## Módulos implementados

- Puestos y tarifas.
- Empleados.
- Clientes y eventos.
- Cotizaciones por evento.
- Bitácora de operaciones.

## Publicar los cambios en Google Apps Script

1. Abre el libro Syhme y entra a **Extensiones > Apps Script**.
2. Reemplaza el contenido del archivo `Code.gs` con la versión de este repositorio.
3. Guarda el proyecto y recarga Google Sheets.

> No se incluyen archivos de autenticación ni configuraciones personales.
